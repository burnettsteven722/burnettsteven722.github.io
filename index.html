常见问题

关于游咔的高频疑问
一条任务失败后额度怎么算？
生成失败不扣产出额度，只扣极少量校验用量。重试与换模型都不会二次计费，直到该条任务产出可用页面为止。
可以同时排队多少条任务？
免费账户同队列 3 条并发，付费账户最高 20 条。队列状态实时可见，前方剩余条数会在任务行里直接标注。
生成的内容部署在哪里？
默认部署在 pages.dev 独立子域并自动启用 HTTPS。绑定 GitHub 后可推送到你的仓库，再接自有域名，全流程无需服务器。
支持哪些生成模型？
目前提供 deepseek-flash、deepseek-pro 与 qwen-long 三档，长文任务建议 qwen-long，短篇批量建议 deepseek-flash，可在任务行内随时切换。
